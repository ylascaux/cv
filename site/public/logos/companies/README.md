# Logos d’entreprises

Ces ressources locales servent uniquement de repères visuels décoratifs dans la chronologie des expériences. Le nom textuel de l’entreprise reste la référence accessible.

## Logos actuels

| ------------------------ | ------------------ | ------------------------------------------------------ |
| `openclassrooms.png`     | OpenClassrooms     | `openclassrooms.com` via Google Favicon Cache          |

Les favicons ont été récupérés le 30 août 2026 avec une taille demandée de 128 px :

```shell
curl -L "https://www.google.com/s2/favicons?domain=DOMAIN&sz=128" -o LOGO.png
```

## Logos historiques

### QOS Energy — version 2020

`qosenergy-2020.png` provient d’une capture du site officiel `qosenergy.com` archivée par Internet Archive le 25 novembre 2020 :

```text
https://web.archive.org/web/20201125073616id_/https://www.qosenergy.com/wp-content/themes/wordpress-bootstrap-master/images/logo.png
```

### SII — version 2014

`sii-2014.png` provient d’une capture du site officiel `groupe-sii.com` archivée par Internet Archive le 22 août 2014 :

```text
https://web.archive.org/web/20140822014949id_/http://www.groupe-sii.com/pfw_files/tpl/structure/home/logo.png
```

Cette version est utilisée pour les expériences `sii-orange` et `sii-orange-business-services`.

### GFI — version 2011

`gfi-2011.jpg` est le fichier historique « Logo GFI 2011 » publié sur Wikipédia le 7 décembre 2011 et crédité à GFI Informatique :

```text
https://fr.wikipedia.org/wiki/Fichier:Logo_GFI_2011.jpg
```

`gfi-2011-mark.png` est une miniature autonome cadrée sur le symbole `gfi` afin qu’il reste lisible dans un jalon de petite taille. Le fichier source est conservé sans modification. Cette version est utilisée pour les trois expériences GFI.

## Utilisation

Ces images restent la propriété de leurs marques respectives et peuvent être soumises au droit des marques. Elles ne doivent pas être réutilisées comme éléments génériques du design.
